# Интерактивная карта касс

Сайт на GitHub Pages. Главный файл: `index.html`.

Публикация: Settings → Pages → Deploy from a branch → main → /(root).

Важно: опубликованная карта общедоступна; не добавляйте персональные данные, пароли, токены или реквизиты. Отметки чек-листов сохраняются локально в браузере.
